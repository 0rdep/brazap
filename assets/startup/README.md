# Startup doodles

Original transparent artwork generated with the built-in GPT Image tool for
Brazap's startup screen. Each PNG is an independent asset; the UI animates the
pieces on Rune's render clock, respects reduced motion, and releases them after
startup. The runtime decodes each image to at most 192 × 192 pixels.

## Prompt set

Shared prompt for each asset:

> Use case: stylized-concept. Asset type: an individual transparent PNG doodle
> for a native dark messaging app loading screen. Subject: [subject below].
> Style: original casual hand-drawn white ink/chalk line art, charming slightly
> irregular double-traced outlines, a few short diagonal hatch marks in corners,
> inspired by pen doodles in a notebook. Clean off-white strokes with transparent
> unfilled interiors. No colored fills, no background, no paper texture, no black
> canvas, no grey backdrop, no typography, no watermark, no grid or extra objects.
> Make the single composition centered and fill about 80% of the square canvas,
> leaving a safe transparent margin. Crisp legible outlines suited to display
> at 80–120 pixels. The image must have genuine alpha transparency.

Subjects:

- `paper-plane.png`: one original folded paper airplane, angled up and to the
  right, with a tiny loose curling flight trail and two short motion ticks.
- `envelope.png`: one original open envelope with a small blank note emerging
  and a tiny outlined heart above the note.
- `chat-bubble.png`: one original rounded speech bubble with three small
  hand-drawn dots, a short curved tail and two tiny playful sparkle strokes.
