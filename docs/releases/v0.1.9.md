## Fixes

- Conversation refreshes retry promptly after a temporary failure, including requests interrupted by sleep. The timeout banner clears automatically once loading recovers.
- Messages sent from your phone now apply saved delivery and read receipts even when those receipts arrived before the message synced to Brazap. Existing archived messages are repaired on startup where receipt data is available.
- Imported conversations use available recipient delivery and read timestamps. Delivery progress is preserved across message replays and phone/LID aliases.
- Read messages display blue double ticks. Delivered messages display gray double ticks, and sent messages display one gray tick.

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary.
