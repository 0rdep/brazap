## Improvements

- The unread badge on the Brazap taskbar icon now counts chats with unread messages instead of individual messages, so a busy chat adds 1 to it. Muted and archived chats are still left out, and the tray tooltip says "unread chats" to match.

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary.

Install through **Restart and update** in the sidebar, or download the binary below. Release binaries are currently unsigned.
