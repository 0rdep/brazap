## Fixes and improvements

- Tags in replies now show names too: the quoted preview reads `@Name` (or `@me`) instead of a raw number.
- The open conversation refreshes after the one-time upgrade that finds tags in existing messages, so names appear without reopening the chat.
- Faster release builds: dependency caches are now reused between releases.

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary.

Install through **Restart and update** in the sidebar, or download the binary below. Release binaries are currently unsigned.
