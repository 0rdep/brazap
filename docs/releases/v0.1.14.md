## Fixes and improvements

- Old update installers are removed from the cache. Only the verified update that is waiting to be installed is kept, which frees about 100 MB per past release.
- Settings → Debug now lists the original WhatsApp history and a combined "other data" row (search index, indexes, stickers), so the rows add up to the database size.

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary.

Install through **Restart and update** in the sidebar, or download the binary below. Release binaries are currently unsigned.
