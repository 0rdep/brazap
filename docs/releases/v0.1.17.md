## Fixes and improvements

- Fixed Brazap staying on the loading screen at startup in v0.1.16. The background service could miss its start signal when the window gained focus first. If you are stuck on v0.1.16, download this version from the release page and run it; the in-app update cannot run from the loading screen.

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary.

Install through **Restart and update** in the sidebar, or download the binary below. Release binaries are currently unsigned.
