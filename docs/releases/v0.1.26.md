## Improvements

This release is about speed on modest computers: laptops with two to four cores, integrated graphics and a slower disk.

- Typing no longer slows down as your chat list grows. The list used to redo its filtering for every row on each keystroke; it now does it once.
- The app does less work while nothing changes. Presence and typing updates from other people no longer make the window reload, each refresh of the chat list loads contacts and aliases once instead of five times, and while Brazap is minimized or in the tray it refreshes less often.
- Animated stickers pause while the window is minimized, covered or in the tray.
- Opening a photo, video, status, call or dialog no longer blurs the whole window behind it. The dark backdrop stays; integrated GPUs no longer redraw and blur every pixel on every frame, which mattered most behind a playing video.
- Starting Brazap does less: the launch no longer reads every message for notification bookkeeping or rewrites every contact alias, and read markers synced from your phone no longer scan whole chats.
- Incoming messages are saved once instead of twice, and received videos download when you play them, as intended, instead of right away.
- Voice transcription uses one CPU thread on computers with up to four, leaving room for the window.
- A downloaded update is no longer re-verified every five minutes while it waits for a restart.
- The startup logo and artwork load from small copies instead of the large originals.

## Diagnostics

`brazap.log` (in `%LOCALAPPDATA%\Brazap\Brazap\data\logs` on Windows) now records which GPU draws the window, when the GPU device has to be recreated or drawing falls back to software, and interface frames that take longer than 100 ms, with what they spent their time on. If Brazap feels slow, that file helps find out why. It contains no messages, names or numbers.

## Downloads

Choose the installer for Windows x64, macOS Apple Silicon, macOS Intel, or Linux x64 (`.deb` or AppImage). Standalone executables are still available for existing installations. `checksums.sha256` contains the SHA-256 digest of each download.

Installed copies update through **Restart and update** in the sidebar. Windows and Linux downloads are unsigned. macOS builds are not notarized yet, so the first launch needs **System Settings → Privacy & Security → Open Anyway** (or `xattr -dr com.apple.quarantine /Applications/Brazap.app`).
