## New

- Make and receive one-to-one WhatsApp voice and video calls. Answer with audio or video, mute the microphone, toggle the camera, and retry a failed call.
- Keep calls in a draggable, always-on-top floating window while using chats or minimizing Brazap. Audio and video share the same call and controls.
- Join video calls without a webcam: unavailable, disconnected, or denied cameras fall back to a clearly labeled black video feed.
- Control calls through the local MCP server with `get_current_call`, `start_call`, `answer_call`, `end_call`, `mute_call`, and `camera_call`.

## Fixes and improvements

- Chats clear their unread badge immediately when opened. Reading on another linked device updates Brazap, and delayed messages no longer reopen already-read history.
- Read state is saved locally before receipts are sent. Pending read synchronization survives disconnection and restarts.
- Text messages appear immediately while sending, with stable message identities and retry support for failed sends.
- Improved Windows notification delivery, chat visibility checks, suppression for the active foreground chat, and duplicate prevention.
- Settings changes apply immediately and rapid edits are saved in order. Font choices load the actual installed faces; System and Monospace now use the platform fonts instead of Inter.
- Floating call windows use a dark native background on Windows, removing the white border. Call state and video updates continue while the main window is minimized.
- Call history and interrupted-call outcomes are retained in SQLite. English, Brazilian Portuguese, and Spanish translations cover the new call controls.
- Updated native build dependencies, macOS camera/microphone permission descriptions, and third-party notices.

## Calling limitations

This is the first live-call release. Group calls, screen sharing, device selection, and acoustic echo cancellation are not included; a headset is recommended. Calls to WhatsApp Cloud API business numbers are not supported for desktop callers by Meta. See [calling details](https://github.com/0rdep/brazap/blob/v0.1.4/docs/CALLING.md).

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary. Existing installations can download this release in Settings → Updates and choose **Restart and install**.

Release binaries are currently unsigned.
