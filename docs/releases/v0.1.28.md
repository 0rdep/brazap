## Improvements

- Several photos and videos sent together now go as an album, the way phones send them: one grid in the chat instead of a row of separate messages. Files and audio files picked in the same batch are still sent on their own, and view-once media is never grouped.
- Text you have typed in the message box becomes the caption when you paste, drop or pick an attachment, with its @mentions. Cancel the preview and the text goes back to the message box.
- An album shows the captions of all its photos and videos under the grid. WhatsApp has no caption for an album itself, so each item carries its own, often only on the first or the last. Brazap used to show only the first one's.
- MCP clients can send albums with the new `send_album` tool. Each photo or video takes its own caption.

## Downloads

Choose the installer for Windows x64, macOS Apple Silicon, macOS Intel, or Linux x64 (`.deb` or AppImage). Standalone executables are still available for existing installations. `checksums.sha256` contains the SHA-256 digest of each download.

Installed copies update through **Restart and update** in the sidebar. Windows and Linux downloads are unsigned. macOS builds are not notarized yet, so the first launch needs **System Settings → Privacy & Security → Open Anyway** (or `xattr -dr com.apple.quarantine /Applications/Brazap.app`).
