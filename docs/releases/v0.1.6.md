## Fixes and improvements

- Improved Ctrl+Left/Right and Ctrl+Backspace/Delete word editing, including punctuation and non-breaking spaces in copied text.
- Ctrl+F (Command+F on macOS) opens and focuses search in the current chat. Search results jump to and highlight the original message, with navigation and older-result pagination.
- Faster sidebar search with a persistent SQLite substring index, immediate chat-name matching, typing debounce, and virtualized results.
- Enter sends messages and attachment captions; Shift+Enter inserts a newline. Reply clicks return focus to the composer.
- On Windows, closing the window keeps Brazap running in the system tray. Click the icon or choose **Open Brazap** to return; **Quit Brazap** exits completely. The shared service continues running while the window is closed, and the main window releases its GPU resources.

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary.

Existing installations can download this release in **Settings → Updates** and choose **Restart and install**. Release binaries are currently unsigned.
