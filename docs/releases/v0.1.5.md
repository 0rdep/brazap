## Fixes and improvements

- Start typing immediately after selecting a chat. The composer also regains focus when replying or sending a message.
- Fixed US International dead-key input on Windows: `~` + Space now inserts `~`, composed accents such as `ã` and `ñ` continue to work, and uncombinable sequences retain both characters.
- Improved standard word-editing shortcuts on Windows and Linux: Ctrl+Left/Right, Ctrl+Backspace/Delete, and Ctrl+Shift selection.
- On Windows and Linux, Home/End follows the current visual line; Ctrl+Home/End moves to the start/end of the message, and Ctrl+Up/Down moves between paragraphs. macOS Command/Option navigation is preserved.
- Added clearer borders and surfaces around the bottom composer, message and caption inputs, attachment/emoji controls, voice-recording button, and header actions. The focused input has a mint outline.

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary.

Existing installations can download this release in **Settings → Updates** and choose **Restart and install**. Release binaries are currently unsigned.
