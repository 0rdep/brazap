## New

- Unread messages now show on the Brazap taskbar icon on Windows as a red count (1–9, then 9+), like Discord. It appears while the app is minimized, in the background or hidden in the tray, and disappears once you read the messages. Muted and archived chats are not counted.
- The tray icon's tooltip shows how many messages are unread.

## Downloads

Choose Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel. `checksums.sha256` contains the SHA-256 digest of each binary.

Install through **Restart and update** in the sidebar, or download the binary below. Release binaries are currently unsigned.
